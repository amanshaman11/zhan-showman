# Zhan Showman — Event Host Website

Landing page for **Жан Шоумен**, professional event host in Kazakhstan.

## Features

- RU / EN / KZ language switcher
- Mobile-first responsive layout
- Portfolio gallery (Swiper + GLightbox)
- Reviews carousel (Swiper)
- Scroll animations (AOS)

## Local development

```bash
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000)

## Deploy on Vercel

1. Push this repo to GitHub
2. Import the project at [vercel.com/new](https://vercel.com/new)
3. No build command needed — static site (`index.html` at root)
4. Deploy

## Structure

```
index.html      # Main page
css/style.css   # Styles
js/i18n.js      # Translations (RU, EN, KK)
js/script.js    # Interactions & plugins
```
